# 🎨 Neeharika's Art Gallery – 12th Grade Digital Portfolio

![Neeharika Art Banner](https://via.placeholder.com/1000x300?text=Neeharika+Art+Gallery+Portfolio)  
*— A Creative Journey in Strokes and Shades —*

Welcome to the official GitHub repository for **Neeharika's Art Gallery**, a minimalist and elegant art portfolio designed to showcase the creative works of Neeharika, a 12th-grade student passionate about drawing and visual expression.

---

## ✏️ About the Website

This digital portfolio was built as a heartfelt project to support Neeharika’s artistic journey and provide a simple online space to:

- Present her hand-drawn artworks professionally
- Build her personal art identity early on
- Share with friends, teachers, and art enthusiasts

Designed entirely using **Canva**, the site includes clean layout, soft color tones, well-spaced images, and clear captions that highlight each piece.
